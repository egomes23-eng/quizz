Como publicar no GitHub Pages

Siga estas etapas para publicar seu projeto online e obter o link do GitHub Pages para entregar o trabalho:

  1. 1. Salve o arquivo principal:
    Crie um arquivo chamado exatamente index.html no seu computador e cole todo o código fornecido.
  2. 2. Crie um Repositório no GitHub:
    Acesse seu perfil do GitHub, clique em New Repository, dê um nome (ex: quiz-quimica) e certifique-se de marcar como Public.
  3. 3. Faça Upload do `index.html`:
    Dentro do repositório criado, escolha a opção Upload files, envie o seu arquivo index.html e clique em Commit changes.
  4. 4. Ative o GitHub Pages:
    Vá nas abas superiores em Settings > menu lateral Pages. Em Branch, mude de None para main (ou master) e clique em Save.
💡 Aguarde de 1 a 3 minutos e recarregue a página de Settings/Pages. O link público ficará disponível em formato: https://seu-usuario.github.io/quiz-quimica/
